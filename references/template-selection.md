# 模板选择与自定义需求

## 收集范围

先检查当前请求和会话中有效的模板要求。用户已经指定的类型、数量、场景和文件名直接进入本次清单；本次明确要求优先于历史模板集合。范围未明确时，再使用结构化问题收集偏好。

优先使用当前模式和工具约束允许的 `request_user_input`。该工具未提供、当前模式不支持或调用明确返回不可用时，直接在对话中向用户提问，等待用户回复。不要为调用工具擅自切换协作模式。使用工具时读取实际 schema，遵守问题数量、选项数量、单选和自由输入能力。

## 常用候选

以下是可扩展的建议目录，用于帮助用户表达需求，不是输出契约，也不是默认全选：

| 候选 | 场景提示 |
| --- | --- |
| 筛选操作列表 | 查询、重置、数据表格、分页和行操作 |
| 基础表单 | 常用字段、必填校验与提交反馈 |
| 复杂表单 | 条件字段、重复项、分步或跨字段约束 |
| 基础弹窗 | 短表单、信息确认或二次确认 |
| 基础抽屉 | 保留上下文的编辑或详情 |
| 详情页 | 信息分组、状态和操作入口 |
| 数据看板 | 指标、筛选联动和数据展示 |

每次按系统上下文提供工具允许数量的相关候选；无额外线索时可优先展示列表、基础表单和复杂表单。问题中明确说明可以自由输入其他类型、业务场景或多个模板名称。弹窗、抽屉、详情页、看板及其他自定义类型始终可通过自由输入指定，不因未显示在选项中而排除。

若工具已有自由输入入口，不添加“其他”或“自定义”占位选项。若工具仅支持单选，不声称支持勾选多个；通过自由输入接收多个模板名称或组合场景。只有组合范围仍有实质歧义时才继续询问。

兼容最多三个选项的 `request_user_input` 调用示例；实际使用以当前工具 schema 为准：

```json
{
  "questions": [
    {
      "header": "模板范围",
      "id": "template_scope",
      "question": "本次需要哪些模板？可选一项，也可自由输入多个名称（如列表和抽屉），或描述其他场景。",
      "options": [
        {
          "label": "筛选操作列表 (Recommended)",
          "description": "包含筛选、表格、分页和操作入口的常用起点。"
        },
        {
          "label": "基础表单",
          "description": "包含常用输入字段、本地校验和提交反馈。"
        },
        {
          "label": "复杂表单",
          "description": "包含联动字段、动态重复项或分步填写。"
        }
      ]
    }
  ]
}
```

直接提问时，用一个简短问题收集模板范围，并附适量常用候选作为参考，同时说明用户可以回复多个模板名称或自定义场景。例如：“本次需要生成哪些模板？常用类型包括列表、表单、弹窗和抽屉，也可以直接描述其他场景或指定多个模板。”候选仅供参考，模板类型和数量由用户回答决定。

## 整理本次清单

将选择和自然语言描述整理为简短清单：

| 模板名称 | 业务场景 | 关键交互与验收条件 | 输出文件 |
| --- | --- | --- | --- |
| 客户筛选列表 | 客户经营 | 查询、重置、分页与行操作可用 | `customer-list.html` |
| 审批详情 | 审批处理 | 详情分组、审批记录、通过与驳回演示 | `approval-detail.html` |

表格仅示例清单格式。清单长度、模板类型、交互内容和文件名由用户需求决定。用户自定义场景与内置候选具有同等地位；不要为了套用候选而丢失用户要求。用户指定文件名时使用其命名，否则按场景给出语义明确且不重复的 `.html` 文件名。

“列表和抽屉”表示两个独立模板；“一个可在行内打开编辑抽屉的列表页”表示一个清单项中的交互，除非用户另要独立抽屉模板。一个自定义场景若有明确的多个独立页面，分别列入清单；无法确定页面边界时询问。

## 等待与继续

- 用户已经给出明确清单时，简述理解后继续生成，不追加一次形式确认。
- 选择结果未知时，不将推荐项、预选状态、空回答或等待超时视为用户选择。可继续做设计文档和技术栈取证；必要的范围信息到达后再生成。
- 用户授权自行决定时，根据系统用途提出并执行本次清单，在交付中说明采用的范围；不自动恢复某个历史固定集合。
- 用户说“全部”时，按本轮明确展示的候选集合解释；集合不明确时先澄清，不自行添加未展示或未确认的类型。
